# 🗺️ BRAN Org Roadmap

Overview of development goals and infrastructure expansion for Brazilian open academic data.

## 🚀 Phase 1: Mapping and Ingestion of Legacy Proceedings (In Progress)
- [x] Extraction and structuring of ABEC Meeting dataset (`abec-open-database`)
- [x] Extraction and structuring of EBBC dataset (`ebbc-open-database`)
- [ ] Ingestion of additional historical proceedings from national conferences

## 📊 Phase 2: REST APIs & Standardized Schemas
- [x] Definition of JSON Schemas v1 (`article.v1.schema.json`, `event.v1.schema.json`)
- [x] Automated CI/CD workflows for data validation and triage
- [ ] Public REST API endpoints with high availability

## 🛠️ Phase 3: Tools & SDKs for Researchers
- [ ] Development of Python package (`bran-py`) for consumption in Pandas/Polars
- [ ] Interactive dashboard for visual analysis of Brazilian bibliometric metrics
- [ ] Integration with open data networks and global indexers (FAIR Data)
