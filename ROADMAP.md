# 🗺️ Roadmap da BRAN Org

Visão geral dos objetivos de desenvolvimento e expansão da infraestrutura aberta de dados acadêmicos brasileiros.

## 🚀 Fase 1: Mapeamento e Ingestão de Anais Legados (Em Andamento)
- [x] Extração e estruturação do acervo da ABEC Meeting (`abec-open-database`)
- [x] Extração e estruturação do acervo do EBBC (`ebbc-open-database`)
- [ ] Ingestão de anais históricos adicionais de simpósios e congressos nacionais

## 📊 Fase 2: APIs REST & Schemas Padronizados
- [x] Definição dos Schemas JSON v1 (`article.v1.schema.json`, `event.v1.schema.json`)
- [x] Automação de CI/CD para triagem e validação de dados
- [ ] Disponibilização de Endpoints REST públicos em alta disponibilidade

## 🛠️ Fase 3: Ferramentas e SDKs para Pesquisadores
- [ ] Desenvolvimento de pacote Python (`bran-py`) para consumo e análise direta em Pandas/Polars
- [ ] Dashboard interativo para exploração visual de indicadores bibliométricos nacionais
- [ ] Integração com redes de dados abertos e indexadores globais (FAIR Data)
