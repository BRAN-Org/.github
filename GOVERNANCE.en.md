**BRAN Org** (**Brazilian Research Archive Network**) is an open initiative dedicated to engineering open-source software, developer tools, libraries, and technical infrastructure for the Brazilian scientific and technical ecosystem.

## Governance Model & Roles

1. **Free Software & Open Data**: We build open-source software (GPLv3) and maintain public data under transparent licensing (CC BY-NC-SA 4.0).
2. **Maintainers, Developers & Auditors**: Repositories and tools are led by core maintainers responsible for architecture and releases, supported by active developers and independent technical/data auditors.
3. **Automated Agents & Official Bots**: The organization deploys **CRONA Bot (`@crona-bot`)** as the automated data guardian (DOI resolution audits, schema enforcement, data PR guarding, and daily calendar syncing) and **BRAN Bot (`@bran-bot`)** for code CI/CD and commit validation. All bot operations are bound to official, audit-grade software identities. The CRONA operational manual is documented in [CRONA.md](CRONA.md).
4. **Technical Decisions & RFCs**: New tools, libraries, schema evolutions, and architecture proposals are debated transparently via Issues and Pull Requests.
5. **Public Commitment**: All tools, software packages, and data catalogs produced by BRAN Org remain accessible, free, and open-source.
6. **Internal Governance**: Operational guidelines and member policies are maintained in the [Contributing Guide (CONTRIBUTING.en.md)](CONTRIBUTING.en.md) and the [CRONA Manual (CRONA.md)](CRONA.md).
