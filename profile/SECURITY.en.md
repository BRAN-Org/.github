# 🔒 Security Policy — BRAN Org

**BRAN Org** takes data security, automation scripts, and API infrastructure seriously.

## 🐛 Reporting Vulnerabilities

If you discover a security vulnerability or accidental data leak in our repositories, please **do not open a public issue**.

Instead, send a confidential email to:
👉 **[gabrielngama@gmail.com](mailto:gabrielngama@gmail.com)**

### What to include:
- Detailed description of the vulnerability
- Steps to reproduce the issue
- Estimated potential impact

We appreciate the support of researchers and developers in keeping open science infrastructure safe.
