# 🆘 Support and Questions — BRAN Org

If you have questions about the project, need help using the bibliometric data, or want to report an issue, please use our support channels:

## 📌 How to get support:

1. **Direct Contact Form**:
   - Send your question or message via our [Contact Form](https://forms.gle/bran-org-contato).

2. **Open an Issue**:
   - To report extraction errors, feature requests, or data inconsistencies, open an **Issue** in the corresponding repository.

3. **Official Email**:
   - For institutional matters or partnerships, email us at: [gabrielngama@gmail.com](mailto:gabrielngama@gmail.com).
